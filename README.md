# UP Shops — ระบบแนะนำร้านค้ารอบมหาวิทยาลัยพะเยา
Database System Project — กลุ่มอาชาบุรุษ สาขาวิศวกรรมซอฟต์แวร์ มหาวิทยาลัยพะเยา

เว็บรวมร้านอาหาร คาเฟ่ หอพัก และบริการรอบมอ พร้อมรีวิว-ให้ดาว ตอบกลับจากร้าน แผนที่-นำทาง และระบบอนุมัติร้านโดยแอดมิน

## การเข้าถึงหน้าต่างๆ
- หน้าร้าน (ผู้ใช้ทั่วไป): `https://horsemenshopdictionary.vercel.app/app/index.html#/`
- หลังบ้าน (แอดมินเท่านั้น): `https://horsemenshopdictionary.vercel.app/app/admin.html#/`
  (ไม่มีปุ่มในเว็บ ต้องเข้าผ่านลิงก์ตรง + ต้องล็อกอิน role admin)
- จัดการร้าน (เจ้าของร้าน): ปุ่ม "จัดการร้านค้า" หลังล็อกอินเป็น owner

# ส่วนที่ 1 — วิธีการใช้งานเว็บไซต์ในแต่ละฟีเจอร์

## ฟีเจอร์ 01 — สมัครสมาชิก / เข้าสู่ระบบ (ผู้ใช้ทั่วไป, เจ้าของร้าน)
1. เปิด `Register.html` → เลือกบทบาท (นิสิต/ผู้ใช้ทั่วไป หรือเจ้าของร้าน)
2. กรอกชื่อ-อีเมล-รหัสผ่าน 2 รอบ → กดยืนยัน (อีเมลซ้ำ/รหัสไม่ตรงมีแจ้งเตือน)
3. ไป `login.html` เข้าสู่ระบบ (กดรูปตาดูรหัสได้) → กลับหน้าแรกพร้อมชื่อผู้ใช้
4. กด Back ตอนล็อกอินอยู่ไม่ค้างหน้า login (ดีดกลับหน้าแรกอัตโนมัติ)

## ฟีเจอร์ 02 — จัดการข้อมูลร้านค้า (เจ้าของร้าน)
1. ล็อกอินเป็น owner → กด **จัดการร้านค้า** (`ownerpf.html`) — ไม่ล็อกอินกดบันทึกไม่ได้
2. ไม่มีร้าน = ฟอร์มเปล่า (โหมดสร้าง) / มีร้านแล้ว = โหลดของเดิมมาแก้ (โหมดแก้ไข มีป้ายบอก)
3. กรอกชื่อ-หมวด-คำอธิบาย-ราคาประมาณ-เบอร์โทรศัพท์ (เพิ่ม/ลบแถวได้)-รูปภาพ (1–10 รูป เลือกปกได้รูปเดียว ลบรูปเก่าได้)-เวลาเปิด-ปิดรายวัน 7 วัน (วันละสูงสุด 2 กะ ข้ามคืนได้)-ปักหมุดแผนที่-สวิตช์ปิดร้านชั่วคราว
4. กดบันทึก → ร้านใหม่รอแอดมินตรวจ / แก้ไขร้านเดิมมีผลทันที / ร้านที่ถูกปฏิเสธบันทึกเป็นคำขอใหม่แถวใหม่ (แถวเก่าคงเป็นประวัติ)

## ฟีเจอร์ 03 — ค้นหา/กรองร้าน (ผู้ใช้ทั่วไป)
1. หน้าแรกพิมพ์ชื่อร้านหรือหมวดในช่องค้นหา (ไม่สนตัวพิมพ์เล็ก-ใหญ่) หรือกดชิป 5 หมวด (อาหาร/คาเฟ่/ร้านค้า/หอพัก/บริการ)
2. ติ๊ก **เปิดอยู่ (Open Now)** เพื่อดูเฉพาะร้านที่เปิด + อนุญาต GPS เพื่อเห็นระยะจริง (ปฏิเสธมีป้าย + ปุ่มลองใหม่)
3. ป้ายเปิด/ปิดขยับเองทุกนาที + การ์ดโชว์เวลาย่อ (เช่น `จ.-ศ. 07:00-10:00, 14:00-20:00 / ส. 10:00-14:00`)

## ฟีเจอร์ 04 — รีวิวและตอบกลับ (ผู้ใช้ทั่วไป, เจ้าของร้าน)
1. เปิดหน้าร้าน (ลิงก์ `#/shop/<id>` แชร์ได้ รีเฟรชไม่หลุด) → ให้ดาว + เขียนคอมเมนต์ (ต้อง login, กันกดส่งซ้ำ)
2. เจ้าของร้านเห็นปุ่ม **ตอบกลับ/แก้ไขคำตอบ** ใต้รีวิวร้านตัวเองเท่านั้น → คำตอบโชว์ใต้รีวิวทันที (แก้ไข = เวอร์ชันใหม่ ได้ประวัติครบ)

## ฟีเจอร์ 05 — นำทาง (ผู้ใช้ทั่วไป)
1. หน้าร้านดูแผนที่ + พิกัด lat,lng + ตารางเวลาเปิด-ปิดรายสัปดาห์ (ไฮไลต์วันนี้)
2. กด **นำทาง (Google Maps)** เปิดพิกัดร้านได้ทันที / ระยะ "ห่างจากคุณ" คำนวณจาก GPS

## ฟีเจอร์ 06 — อนุมัติร้านค้า (แอดมิน)
1. เปิด `admin.html` ผ่านลิงก์ตรง (ต้อง role admin) → ตารางรออนุมัติ (ชื่อร้าน/หมวด/คนขอ/วันที่ขอ) + การ์ดสถิติ
2. กด **อนุมัติ** (ร้านขึ้น Home) / **ปฏิเสธ** (คงแถวไว้เป็นประวัติ ไม่ขึ้น Home) — ทุกปุ่มมีกล่องยืนยัน + ตรวจว่าลง DB จริง

# ส่วนที่ 2 — โครงสร้าง Database ของเว็บไซต์ (ฟีเจอร์ไหนแตะตาราง/ฟิลด์ไหน)

## ฟีเจอร์ 01 → ตาราง `User` (+ Supabase Auth)
| ฟิลด์ | ใช้ตรงไหน |
|---|---|
| `UserEmail` | สมัคร/login/ผูกตัวตน (เก็บตัวเล็กทั้งหมด) |
| `Username` | ชื่อที่โชว์ + ชื่อคนขอในจอแอดมิน |
| `UserPassword` | legacy (รหัสจริงอยู่ฝั่ง Auth แบบ bcrypt) |
| `role` | แยก user / owner / admin |
| `UserShopID → Shop.ShopID` | ผูกเจ้าของกับร้าน (owner 1 คนมี 1 ร้าน, ร้านหนึ่งมีได้หลาย owner) |

## ฟีเจอร์ 02 → ตาราง `Shop` + 4 ตารางลูก
| ตาราง/ฟิลด์ | ใช้ตรงไหน |
|---|---|
| `Shop(ShopName, ShopDescription, ShopCategoryId → Category, ShopAvgPrice, ShopLocation, ShopManualStatus, ShopOperatingNote, ShopApprovalStatus, ShopCreatedAt)` | ข้อมูลหลัก + สถานะอนุมัติ (Pending/Approved/Rejected) |
| `ShopPhoneNumber(ShopID, ShopPhoneNumber)` | เบอร์หลายเบอร์ (ลบเขียนใหม่ทุกครั้งที่บันทึก) |
| `Shop_Image(ShopID, ShopImageNo, ShopImageURL, ShopIsCover)` | รูปหลายรูป ปกเดียว (+ไฟล์ใน bucket `shop-images`) |
| `Operating_Hours(ShopID, DayOfWeek 1–7, ShiftNo, OpenTime, CloseTime)` | เวลารายวัน วันละสูงสุด 2 กะ |

## ฟีเจอร์ 03 → อ่านอย่างเดียว (ไม่เขียนเพิ่ม)
| ตาราง/ฟิลด์ | ใช้ตรงไหน |
|---|---|
| `Shop (เฉพาะ Approved)` | รายการร้านหน้า Home |
| `Category(CategoryName)` | ชิป 5 หมวด |
| `Operating_Hours` | เทียบเวลาเครื่อง ได้ป้ายเปิด/ปิดเรียลไทม์ |
| `Review` | เฉลี่ยดาวแต่ละร้าน |

## ฟีเจอร์ 04 → ตาราง `Review` + `Review_Replies`
| ตาราง/ฟิลด์ | ใช้ตรงไหน |
|---|---|
| `Review(ReviewShop, ReviewUser → User.UserID, ReviewRating, ReviewComment)` | รีวิว + คำนวณดาวเฉลี่ย |
| `Review_Replies(ReviewID, ReplyNo ต่อเลข, UserID, ReplyText)` | คำตอบเจ้าของร้าน (โชว์แถว `ReplyNo` สูงสุด) |
| `User.Username` | ชื่อคนรีวิว/คนตอบ |

## ฟีเจอร์ 05 → อ่าน field เดียว
| ตาราง/ฟิลด์ | ใช้ตรงไหน |
|---|---|
| `Shop.ShopLocation ("lat,lng")` | วาดแผนที่ + ปุ่ม Google Maps + คำนวณระยะ Haversine ฝั่งหน้าเว็บ (ไม่เก็บระยะลง DB) |

## ฟีเจอร์ 06 → ตาราง `Shop` (+ อ่านประกอบ)
| ตาราง/ฟิลด์ | ใช้ตรงไหน |
|---|---|
| `Shop (where ShopApprovalStatus = 'Pending')` | ตารางรออนุมัติ |
| เขียน `Shop.ShopApprovalStatus → Approved/Rejected` | ปุ่มอนุมัติ/ปฏิเสธ |
| `Category` + `User(UserShopID)` | ชื่อหมวด + ชื่อคนขอในตาราง |
| นับจำนวน `Shop`/`User` | การ์ดสถิติ |
